# Entrada

Aqui se tira lo que traes en la cabeza, sin decidir donde va. Una idea, un pendiente, algo que te dijeron, un enlace.

Un archivo por cosa, o una lista en uno solo. Da igual el formato: `/ordenar` lo clasifica contigo y deja esto vacio.

Si esta carpeta pasa de 15 elementos, el sistema empieza a avisar.
