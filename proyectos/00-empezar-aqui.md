# Empezar aqui

Estado: activo
Creado: 2026-08-31

## Objetivo

Aprender el ciclo completo de este espacio usandolo una vez de verdad, con cosas tuyas.

## Criterio de cierre

- Corriste `/hoy` y te propuso algo de este proyecto.
- `entrada/` quedo vacia despues de correr `/ordenar` con al menos tres cosas tuyas dentro.
- Existe en `proyectos/` un proyecto real creado con `/proyecto`, con criterio de cierre que se puede mirar.
- Este archivo esta en `archivo/` (lo mueve `/cerrar` cuando todo lo de arriba se cumpla).

## Tareas

- [ ] escribir en entrada/ tres cosas que traes en la cabeza (una por archivo, o una lista)
- [ ] correr /ordenar y clasificarlas con el agente
- [ ] correr /proyecto y definir tu primer proyecto real
- [ ] correr /hoy manana y empezar por lo que proponga
- [ ] correr /cerrar sobre este proyecto

## Notas

Este es el unico proyecto que viene de fabrica. Cuando lo cierres, el espacio es tuyo.
