# Proyectos

Lo que tiene final y requiere varios pasos: una mudanza, un tramite, un viaje, un cambio de trabajo.

Un archivo por proyecto, numerado (`01-mudanza.md`). Se crean con `/proyecto`, que obliga a escribir el **criterio de cierre**: como se ve terminado, en cosas que se pueden mirar. Sin esa seccion, las verificaciones fallan a proposito.

Cuando el criterio se cumple, `/cerrar` lo mueve a `archivo/`.
